1. 一句话总结

小云雀当前可被证实为一个以多场景创作入口、对话式创作、短剧工作台、节点画布、历史与资产管理为表层能力的 AI 视频创作产品；其真实 Agent 编排、生成服务、模型路由、任务队列与质量治理均缺少执行证据，只能作为待验证能力或建议架构呈现。

2. 证据来源与缺口

直接证据

  • E01–E03：首页入口、自然语言输入、素材引用、技能、偏好与生成按钮。
  • E04：短剧 Agent 2.0、剧本输入限制、四种工作入口、Seedance 2.5 宣传语。
  • E05–E06：自由画布自动建项、保存状态、节点类型、综合助手、比例和分辨率。
  • E07–E09：历史 0 条、未命名项目、作品资产空状态与资产分类。
  • E10–E11：余额可见，但生成、失败、预览与交付无证据。

核心缺口

  • 没有真实用户消息、Agent 回复、规划摘要或工具执行。
  • 没有成功、失败、余额不足、安全拦截、中断和重试样本。
  • 没有剧本解析结果、角色/场景/分镜、图片、视频、音频资产。
  • 没有模型调用参数、队列、扣费、版本、质量评估和发布记录。
  • 无法确认 4 个 Agent 名称是否对应独立后端 Agent。

  • 自由画布具有节点式对象模型的界面迹象，并带综合助手。
  • 进入自由画布立即创建并保存项目，浏览与建项没有分离。
  • 历史、首页项目侧栏和作品资产是不同状态面；它们之间的统一状态源不可见。
  • Agent 身份存在于页面命名，但真实 Agent 编排、工具调用和交接无法确认。
  • 模型层只确认 Seedance 2.5 名称与智能匹配入口，不能确认真实调用。

16. 风险清单

P0 状态冲突与口头完成

历史、项目、画布和资产可能各自显示不同状态；若 Agent 仅凭工具结果宣布完成，会交付不存在的资产。

控制：统一状态源+完成验证门。

P0 重试重复扣费/重复资产

缺少幂等和扣费状态时，网络重试可能造成重复生成。

控制：幂等键、冻结/结算账本、未知扣费不自动重试。

P0 中断后继续执行

长任务若未传播取消事件，用户中断后仍可能继续消耗额度。

控制：取消令牌、状态守卫、任务事件审计。

P0 私有资产泄漏

角色、商品、上传素材若与公共模板或其他用户引用混淆，会产生严重隐私与版权风险。

控制：租户隔离、授权引用、来源与用途审计。

P1 缺少依赖失效

剧本或角色变化后，下游视频可能仍引用旧版。

控制：版本化依赖图和 stale 传播。

P1 时长、风格与角色漂移

整剧生成容易出现镜头时长、风格、角色连续性和台词不一致。

控制：分项评估、镜头级指标、人工确认门。

P1 安全错误处理不透明

若错误被归因于“随机误判”或不给修改建议，用户无法恢复。

控制：可见规则版本、错误分类和合规修正路径。

P1 模型/知识过期

技能、模板与模型限制若版本不同步，会导致不可执行参数。

控制：能力注册表、兼容矩阵、知识版本和灰度路由。
